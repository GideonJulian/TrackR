# 🚀 Trackr

Trackr is a modern job tracking app that helps you stay organized during your job search.

Instead of juggling notes, tabs, and spreadsheets, everything lives in one clean dashboard.

Track applications, update statuses, upload resumes, and manage your career journey in one place.

---

## ✨ Features

* 🔐 JWT Authentication
* 📌 Track Job Applications
* 📄 Resume Uploads
* 📊 Dashboard Analytics
* 📱 Responsive Design
* ☁️ Cloud Deployment

---

## ⚙️ Installation

### Clone the Project

```bash
git clone https://github.com/yourusername/trackr.git
```

### Frontend Setup

```bash
cd client
npm install
npm run dev
```

### Backend Setup

```bash
cd server
npm install
npm run dev
```

---

## 🔑 Environment Variables

Create a `.env` file inside the `server` folder:

```env
PORT=4000
MONGO_URI=your_mongodb_uri
JWT_SECRET=your_secret
```
